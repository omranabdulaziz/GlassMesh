Wayland protocols used by GlassMesh that aren't in every `wayland-protocols` version:

- `ext-background-effect-v1.xml`: from `wayland-protocols` 1.45 (staging), MIT license.
- `kde-blur.xml`: `blur.xml` from KDE's `plasma-wayland-protocols` 1.10, LGPL-2.1-or-later.

Both let the compositor blur what is behind a see-through window.
